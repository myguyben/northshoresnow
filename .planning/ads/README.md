# Google Ads import files

Generated by `node .planning/ads/build-import.mjs`. Edit the script, never the CSVs —
it validates every asset against the platform's character limits and refuses to write
if anything is over. (It already caught one: `property-managers` is 17 characters against
a 15-character display-path limit.)

**4 campaigns · 8 ad groups · 45 keywords · 111 headlines · 252 negatives.**

## Everything imports Paused

No campaign, ad group or ad in these files can spend on import. Enable them by hand,
one at a time, after the checks below.

## Import order

Google Ads Editor needs each level to exist before the one inside it, so import in order:

1. `01-campaigns-adgroups-keywords.csv` — structure and keywords
2. `02-responsive-search-ads.csv` — the ads
3. `03-negative-keywords.csv` — negatives
4. `04-sitelinks.csv` — sitelink extensions

In Editor: **Account → Import → From file**, review the proposed changes, then **Post**.
Editor shows a diff before anything is committed — read it.

## Set by hand afterwards

These are campaign settings the CSV format does not carry, and two of them decide whether
the money works at all:

- **Location targeting** — North Vancouver (City + District), West Vancouver, City of
  Vancouver. Add Lions Bay to S1 only.
- **Location option → "Presence"**, not the default *presence or interest*. The default
  serves anyone searching *about* the area, which is how you end up paying for Vancouver,
  Washington. The `washington` / `wa` negatives in file 03 are the second line of defence,
  not the first.
- **Networks** — Search only. Turn Search Partners and Display **off**.
- **Bid strategy** — Maximize Clicks with the $6.00 cap already in file 01 for the first
  two to three weeks, then Maximize Conversions once ~20 conversions have landed.
- **Ad schedule** — S1/S2/S4 business hours; S3 always on.
- **Auto-applied recommendations → off.** Google will otherwise widen the keywords and
  quietly undo the negatives.
- **Call extension** (604) 990-7072 with call reporting, and link the Google Business
  Profile for the location extension and seller ratings.
- **S3 Storm Surge** also wants a call-only ad — nobody fills in a form mid-storm.

## Do not enable anything until tracking is live

Conversion tracking is built but inert. Until the `PUBLIC_*` IDs are set on the Render
static site and a test lead has been verified end to end, every dollar spent here is
unmeasurable — you would not be able to tell which click produced a quote. Full sequence
in `../ADS_LAUNCH_KIT_2026-08-13.md` §5.
